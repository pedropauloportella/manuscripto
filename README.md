# manuscripto
Sistema de gestão editorial para publicações acadêmicas que cobre o ciclo: submissão, revisão, edição, versionamento, publicação e distribuição, com suporte a livros, capítulos, dossiês e artigos. Inclui portal para autores, revisores e editores, catálogo público,  para facilitar fluxos editoriais configuráveis e automação de operações.
